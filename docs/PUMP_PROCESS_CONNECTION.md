# Native pump to process connection handoff

`pump_operation_to_process_connections()` converts each accepted point in an owner-issued `PumpOperationTrace` into the existing `equipment.ConnectionTransfer` API. The bridge requires the exact native LH2DT property provider, an explicit `Lh2dtProperties` reference basis, node IDs and source evidence. The pump trace now records receiver absolute pressure at each accepted time, since a mutable downstream state may vary during a run and its final value cannot represent earlier points.

At each sample the bridge preserves time in seconds, clock ID, native forward mass flow in kg/s, native shaft input in W, outlet enthalpy in J/kg, pressure in Pa absolute, distinct ports and accepted capacity/NPSH status. It reconstructs the outlet thermodynamic state at the accepted pressure and enthalpy through the same property provider and checks fluid, energy reference and hydrogen spin basis identity. `require_current()` replays the pump trace freshness check and validates the issued connection series seal.

The handed-off `shaft_work_w` is pump shaft work into the fluid. It is not motor input electricity, heat, grid demand, or an efficiency-adjusted facility utility. The point series is sampled operation data; it does not integrate energy between samples, solve downstream pressure/network flow, add a motor, or establish pump-map qualification. The deferred Hangang contract `pump-operation-shaft-connection-boundary` is registered under `pump-operation`; the profile's existing thermo and LH2DT provider requirements apply.
