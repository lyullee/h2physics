## 실행 기록과 제한

- 기존 기능: regression-original.xml/log, regression-original-run.json. pytest6.11초, 프로세스7.11초.
- 장비·저장: equipment-runs.xml/log, equipment-run.json, equipment-summary.json. pytest5.01초, 프로세스5.86초.
- 생산·안전: process-final.xml/log, process-run.json, process-results.json. pytest5.46초, 프로세스6.45초.
- 세 실행은 독립 작업으로 진행했다. 이 시간은 계산 실행 시간이며 시험 준비·정리 시간을 포함한 전체 작업 시간은 아니다.
- 최초 대표 시험의 두 오류는 시험 코드의 잘못된 종료 상태명과 PV압력 필드 경로였다. 시험 기대값/조회 경로만 수정하고 원래 실패 기록은 보존했다.
- 구획 계산의 기존 유한수 보호식에서 scalar-divide RuntimeWarning1건이 발생했다. 실제 출력은 유한하고 기본 검사는 통과했다. 사용자 범위에 맞춰 추가 심화 조사나 제품 코드 수정은 하지 않았다.
- 기존 연결 분류72정상/2거부경계/2외부차단/2연결대상없음은 그대로다. 이번 실행에서 해당6개 경로를 재개하거나 외부 엔진을 수정하지 않았다.

## 재실행

기존 기능의 정확한 선택 명령은 regression-original-run.json에 보존했다. 대표 시험은 h2physics-py312환경과 기존 검토된 선택 의존성을 사용하고 아래 두 파일을 별도 프로세스에서 실행하면 된다.

```powershell
python -m pytest tests/test_representative_run_equipment.py -q -o junit_family=xunit1
python -m pytest tests/test_representative_run_production_safety.py -q -o junit_family=xunit1
```

실제 실행에서는 PYTEST_DISABLE_PLUGIN_AUTOLOAD=1, MPLBACKEND=Agg와 각 수치 라이브러리 스레드 수1을 사용했다. 각 실행 기록에는 정확한 명령, 소스 해시와 반환 코드가 있다. 새 심화 시험이나 전 모델의 종단간 자격 검증은 후속 목표로 자동 추가하지 않는다.
