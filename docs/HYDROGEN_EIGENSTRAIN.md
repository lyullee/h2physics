# Hydrogen concentration eigenstrain and cylinder stress

`HydrogenConcentrationEigenstrainProfile` maps a caller-supplied radial mobile-hydrogen concentration onto isotropic linear free strain:

```text
epsilon_H(r) = beta * (C(r) - C_reference)
```

`C` is mol of the declared `HydrogenCarrier` entity per cubic metre. `beta` (`linear_expansion_m3_per_mol`) is an explicit linear strain coefficient in m³/mol of that entity. It is never populated from a material name or inferred from an adsorption, permeation or fatigue dataset. When a source gives volumetric partial molar expansion for isotropic insertion, mapping it to this linear coefficient requires a separately justified one-third conversion. The profile retains its concentration-basis label, source/profile identity, reference concentration and temperature, and rejects changed arrays or labels.

`radial_hydrogen_eigenstrain_cylinder()` reuses the existing static axisymmetric long-cylinder BVP. It returns the pressure-plus-temperature baseline, the combined pressure/temperature/hydrogen field, and component-wise hydrogen-only stress increments from the difference of those solves. The result is solver-issued; `require_current()` detects changes to the increment arrays, retained baseline/combined fields, and profile before its combined von Mises projection is returned. Von Mises stress is nonlinear, so its increments cannot be added. Open/closed ends and free/fixed axial restraint retain the existing cylinder contracts.

`radial_hydrogen_eigenstrain_history()` accepts caller-supplied time, pressure, temperature and concentration/eigenstrain profiles, then performs an independent static solve at each exact sample. `RadialHydrogenEigenstrainStressHistory` retains the common clock and solver-issued results; `sample_at()` does no interpolation. If a later solve fails, `RadialHydrogenEigenstrainHistoryError` retains the failed index, accepted sample prefix and original cause. All samples must retain the same carrier, concentration basis, reference concentration, linear expansion coefficient and temperature reference. This is a quasi-static sequence, not concentration evolution, stress/diffusion feedback, or an integrated transient.

For direct coupling from the shared cylindrical finite-volume diffusion solver, `h2physics.adapters.bind_cylindrical_transport_to_eigenstrain()` accepts its `TransportResult`, exact-clock pressure and temperature records, and caller-supplied inner/outer solid concentration values at every source time. It places those explicit surface values around the original cell-center mobile concentrations, then retains both the transport and resulting stress histories in a freshness-checked binding. The transport mesh bounds must match the cylinder exactly. The API requires the carrier basis, reference concentration and temperature, linear expansion coefficient, clock identity, evidence for the clock join, and separate evidence for axial uniformity of the radial concentration field. It does not include trapped concentration, infer surface concentrations, or close the diffusion/mechanics feedback loop. The BVP uses its documented PCHIP radial representation on the supplied boundary-and-center nodes; it makes no claim that this reconstruction is experimentally qualified.

The constitutive assumption is isotropic, homogeneous, linear-elastic response with constant moduli and an isotropic hydrogen eigenstrain. The API has no surface chemistry, phase change, plasticity, damage or fracture-initiation law. The caller must ensure that the concentration basis and coefficient describe a compatible material, phase and reference state.

Primary method references: Frolova et al., *On modeling of stress-induced diffusion within micropolar and classical approaches*, DOI [10.1002/zamm.202100505](https://doi.org/10.1002/zamm.202100505), for isotropic hydrogen eigenstrain in a classical constitutive relation; and Connolly, Malavé, and Martin, *Hydrogen concentration-induced stresses in an environmental TEM*, Physical Review Materials 6, L040601 (2022), DOI [10.1103/PhysRevMaterials.6.L040601](https://doi.org/10.1103/PhysRevMaterials.6.L040601), for concentration-gradient-induced stress. Their parameter values and worked examples are not imported into this API. The synthetic BVP and transport-coupling contracts are deferred for remote execution on Hangang; they provide no material qualification.
