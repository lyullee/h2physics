# Prepared request: alkaline electrolysis bubble data schema

**Status:** prepared, not sent.

**Dataset:** Pandey and de Groot, *Oxygen sticks, Hydrogen glides: Bubbles in
alkaline water electrolysis*, Mendeley Data v2,
[10.17632/r6np4f7gmf.2](https://doi.org/10.17632/r6np4f7gmf.2).

The public root listing and README have been acquired. Please provide or point us to:

1. Folder identifiers or a complete nested-folder inventory, including the figure
   data, processing scripts, and their file formats, byte sizes, and checksums.
2. For each processed table: column names, units, missing-value conventions,
   row/group identifiers, and experimental-condition mapping.
3. For image/video-derived quantities, spatial calibration, frame-time mapping,
   segmentation/measurement method, and whether numeric bubble tracks or only
   source videos are deposited.
4. The mapping from each observation to hydrogen/oxygen gas, electrode,
   polarity, current density, electrolyte composition, temperature, pressure,
   and operating step.
5. Whether paired voltage, cell resistance, active-area, or hydrogen-rate data
   exist for the same condition/time windows.
6. Preferred attribution for any derived tabular extracts.

This request seeks technical schema clarification only. The public record declares
CC BY 4.0. It does not request permission to use data offered under that license,
and has not been sent.
