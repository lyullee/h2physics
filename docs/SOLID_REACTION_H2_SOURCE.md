# Finite H2 source from a solid-reaction product takeoff

`source_from_solid_reaction_hydrogen` exposes actual accepted H2 withdrawal
from an original `SolidReactionTrace` through the shared `IntervalMassSource`
contract. It does not use gross hydrogen generated by reaction: every output
mass bin comes from the corresponding accepted step's species-resolved
`removed_mol` ledger multiplied by that reaction species' molar mass.

```python
from h2physics.adapters import source_from_solid_reaction_hydrogen

handoff = source_from_solid_reaction_hydrogen(
    trace,
    location=source_location,
    gas_state=hydrogen_thermo_state,
    location_projection_evidence_id="case-specific-product-plane-projection",
)
handoff.require_current()
finite_source = handoff.source
```

Admission requires a contiguous one-clock schedule, exactly one neutral
gaseous H2 species, and no co-withdrawn species above the reaction model's
declared amount tolerance. The supplied `ThermoState` must be gaseous H2 with
the trace's exact molar-enthalpy reference and match the product pressure and
temperature at every step. The provider's H2 molar enthalpy is compared with
the supplied specific enthalpy, and each step's total withdrawal enthalpy must
match that H2-only export. The handoff retains original source origin,
reaction/evidence provenance, provider-reconstructed initial/final system
enthalpies for its whole-system conservation budget using the exact provider
owned by the retained kernel with matching species order and energy basis, the producer process ID
on the source location, the trace content seal, and the finite source
fingerprint; `require_current()` rejects changes to either side.

`SourceLocation` is caller-selected because the solid reaction trace has no
spatial product-plane model. Evidence for that projection is mandatory. The
result can feed existing finite-source safety/consequence consumers, but this
adapter does not model a separator, outlet piping, pressure control, a nozzle,
dispersion or ignition. The representative gas state is an explicit boundary
projection; it is not a claim that a pressure or temperature control device
exists.

The deferred Hangang case
`solid-reaction-hydrogen-finite-source-handoff` uses a synthetic core-only
reaction fixture to check exact takeoff bins, provider enthalpy compatibility,
substitute-provider rejection, reference rejection, and stale-producer detection. It does not validate
commercial hydride chemistry, product separation, or atmospheric release.
