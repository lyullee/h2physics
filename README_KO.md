# h2physics — 수소 설비·저장·안전 물리 모델

**모듈 바로 찾기:** [목적·입력·출력 표](#모듈별-목적입력출력) · [전체 파라미터·반환값 명세](https://github.com/lyullee/h2physics/blob/main/docs/MODULE_IO_REFERENCE.md).

수소 생산, 저장, 이송, 재료 거동과 사고 결과를 Python 객체로 계산하고 연결하는 연구용 라이브러리입니다. 파라미터 객체·함수·NumPy 배열·시간 이력을 직접 전달하므로 별도 서버나 직렬화 형식이 필요하지 않습니다.

현재 버전은 **0.2.0 Alpha**입니다. [PyPI 0.2.0](https://pypi.org/project/h2physics/0.2.0/)과 [Zenodo 0.2.0 DOI](https://doi.org/10.5281/zenodo.23889027)를 공개했습니다. [8개 보완 모델과 시험 기록](https://github.com/lyullee/h2physics/blob/main/docs/ENHANCEMENTS_20261102.md)에 실내 축적·조건부 과압, FA/DDT 선별, 기계적 팽창 에너지, 선형 구조 동응답, 열사이클·엑서지, 고체 산화환원 평형, 전극 측정 분석, PAR 열·유동·수소 제거 연동의 범위와 결과를 기록했습니다. 신규 92건과 관련 기존 47건의 선택 검사를 환경별로 완료했으며, 실측 정확도와 시설 적합성은 별도 검증 대상입니다.

[PyPI](https://pypi.org/project/h2physics/), [GitHub 릴리스](https://github.com/lyullee/h2physics/releases), [Zenodo 버전 이력](https://doi.org/10.5281/zenodo.23886389)을 통해 버전별 배포본을 확인할 수 있습니다. 실제 게시·설치·파일 확인 결과는 [배포 상태](https://github.com/lyullee/h2physics/blob/main/docs/PUBLICATION_STATUS.md)에 기록합니다. [영문 README](https://github.com/lyullee/h2physics/blob/main/README.md), [빠른 시작](https://github.com/lyullee/h2physics/blob/main/docs/QUICKSTART.md), [상세 사용자·연구자 안내](https://github.com/lyullee/h2physics/blob/main/docs/USER_GUIDE_KO.md)를 함께 사용하세요.

## 모듈별 목적·입력·출력

아래에서 **할 일 → Python 호출 → 필요한 입력 → 반환 결과**를 바로 고를 수 있습니다. `h2physics.` 아래의 실제 모듈 경로와 호출명을 표시했습니다. 외부 엔진 연결 객체, 물리 계산, 자료 분석·집계는 목적 설명으로 구별합니다.

**기존 카탈로그 82개 식별자를 모두 연결**하고, 같은 분야의 주요 선택 수준과 0.2.0 보완 API, 공통 연결 객체도 별도 행으로 표시했습니다. 행 수는 독립 물리 모델 수나 검증 완료 개수가 아닙니다.

입력 칸은 **주요 파라미터 이름**입니다. `구성`은 생성자, `호출`은 계산 메서드의 인자입니다. `…`가 있으면 나머지 인자가 있습니다. 각 호출 링크의 [전체 입출력 명세](https://github.com/lyullee/h2physics/blob/main/docs/MODULE_IO_REFERENCE.md)에서 **전체 인자·타입·기본값·반환 필드·원본 코드**를 확인하세요. 한 행은 해당 분야의 선택한 사용 경로이며, 다른 수준과 적용 한계는 분야별 설명서를 함께 확인합니다.

단위 접미사는 `_pa`=Pa, `_k`=K, `_kg`=kg, `_mol`=mol, `_s`=s, `_w`=W, `_j`=J, `_m`=m이며 조합 단위도 이름에 표시합니다. 유체 상태 압력은 절대압이고, 압력차·과압·잔차는 해당 API가 정한 차이 기준입니다. `basis`·`evidence`·`clock_id`·공급자 객체는 물질/에너지 기준·근거·시간축·실제 엔진을 지정하는 입력입니다. 스칼라나 배열의 물리적 의미와 형상은 연결된 객체 명세·사용 설명서를 따릅니다.

## 설치와 첫 실행

기록된 기준 환경은 Python 3.12입니다. 저장소를 내려받은 후 가상환경을 활성화하고 필요한 기능만 설치합니다.

```bash
git clone https://github.com/lyullee/h2physics.git
cd h2physics
python -m venv .venv
python -m pip install --upgrade pip
python -m pip install -e ".[thermo,hydraulics,test]"
```

PowerShell 활성화는 `.venv\Scripts\Activate.ps1`, POSIX 셸은 `source .venv/bin/activate`입니다. PyPI 설치 명령은 `python -m pip install "h2physics[thermo,hydraulics]"`입니다. 개발 시에는 위 소스 설치를 사용하세요.

```python
from h2physics.thermo import CoolPropProperties

state = CoolPropProperties("Hydrogen").state_pt(200_000.0, 300.0)
print(state.density_kg_m3)
print(state.enthalpy_j_kg)
print(state.basis)
```

압력은 절대압 Pa, 온도는 K입니다. 물성·수력학·전기화학의 실제 호출 예제와 오류 처리는 [빠른 시작](https://github.com/lyullee/h2physics/blob/main/docs/QUICKSTART.md)에 있습니다.

## 단위와 연결 규칙

- 기본 단위는 Pa 절대압, K, kg, m, s입니다. 게이지압·섭씨·정상체적 유량은 명시적으로 변환합니다.
- H와 H₂의 운반체 기준, 상, 스핀 조성, 엔탈피 기준을 유지합니다.
- 시간축 이름만 같다고 실제 시각·지지 구간이 일치하는 것은 아닙니다.
- 유량 하나를 완전한 사고 방출원으로 취급하지 않습니다. 개구·위치·재고·상·종료 조건이 필요합니다.
- 결과 소유자와 기준을 요구하는 수신 API에는 원본 결과를 전달합니다. 결과를 복사하거나 이름만 바꿔 자격을 만들어서는 안 됩니다.
