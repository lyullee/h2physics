# 자체 모델 실측 비교 1차 — 2026-11-02

실제 측정값을 대상으로 자체 모델4종의 조건부 예측 비교를 실행했다. 계수를 추정하는 자료와 평가용 자료를 곡선·온도·실험 배치·운전 조건 단위로 분리했다. 기존 GitHub 엔진 내부 물리와 전체 연결 시설의 물리 검증은 제외했다. CoolProp은 기존 물성 공급자로 사용했으며 EOS 정확도를 검증한 것이 아니다. 제품 모델 코드는 변경하지 않았다.

**이번 결과는 실험 비교를 실행한 근거이며, 독립 실험과 불확실성까지 확보된 물리 자격 검증 완료를 뜻하지 않는다. 네 대상 모두 qualification 상태는 false로 유지한다.** 임의의5%같은 공통 합격 기준을 만들거나 평가 자료에 맞춰 모델을 다시 조정하지 않았다.

## 1. 유효 수소 투과식

출처는 [Ververs·Arratibel·Di Felice·Gallucci의 측정 데이터](https://zenodo.org/records/10691625), CC BY4.0이다. 순수 수소 공급압1.5–5bar(a), 투과측1bar(a),350/400/450°C를 사용했다. 네 막의350·450°C자료64점으로 온도 의존 유효 투과계수를 추정하고,400°C곡선32점 전체를 평가용으로 남겼다.

기존 steady_permeation과 지수0.5의 PowerLawSolubility를 사용했다. 압력 대신 실제 CoolProp 순수 수소 퓨가시티를 입력했다. 식별되는 값은 K=J/(sqrt(f_up)−sqrt(f_down)), 단위 mol/(m²·s·sqrt(Pa))의 유효 계수다. D·S·두께를 따로 안다고 가정하지 않았다. 코드의 단위 기준 응답은 D*S/L를 인수분해하기 위한 수치 기준이며 실제 시편 치수가 아니다.

| 막 | 평가점 | 평균 절대 상대오차 | 최대 절대 상대오차 |
| --- | ---: | ---: | ---: |
|S-PdAg-YSZ/Al₂O₃|8|3.27%|7.52%|
|S-PdAg-HT|8|4.06%|10.50%|
|S-Pd|8|2.15%|4.55%|
|S-PdAg|8|2.92%|6.82%|

같은 장치 내 온도 보간의 근거다. 개별 막층 물리, 고유 확산계수·용해도, 혼합기체, 다른 온도·압력 범위로 확대하지 않는다. 점별 측정 불확실성과 독립 반복 실험이 없어 불확실성 기반 합격 판정은 하지 않았다. 기존 수소 투과 자료3종은 경계조건·정규화·보정 정보가 부족해 물리 비교에 사용하지 않았고 차단 사유를 보존했다.

## 2. 수소화물 반응분율

출처는 [Neves 등의 AB2반응 데이터 v1.0](https://zenodo.org/records/16458050), CC BY4.0 및 연결 논문 DOI10.1016/j.egyai.2025.100659이다. 측정 기반144곡선의 unsmoothed Alpha만 사용했다. 작성자 코드, 작성자가 추정한 계수, 모델 분류, smoothed Alpha와 NN Output은 사용하지 않았다.

D/E/F/G100곡선으로 기존 HydrideKinetics·ArrheniusRate·VanthoffPlateau의 계수를 보정하고 H배치44곡선을 평가했다. 평가 곡선은 흡수22개·5162점, 탈착22개·13021점이다. 첫 측정값을 알려진 초기조건으로 사용하고, 모든 평가 행을 남겼다. 최초 영 초기값 가정의 오류를 수정한 기록도 별도로 보존했다.

| 평가 분기 | 곡선별 RMSE평균 | 곡선별 MAE평균 | 곡선별 편향평균 |
| --- | ---: | ---: | ---: |
| 흡수 |4.49096%p|2.92772%p|−1.07639%p|
| 탈착 |4.86232%p|3.43453%p|+1.25824%p|

이는 각 실험의 관측 최대 용량으로 이미 정규화된 반응 진행도다. 따라서 절대 저장량·용량을 예측한 검증이 아니다. 평균 압력·온도만 제공돼 실제 변화 이력을 복원하지 않았으며, 압력의 절대/게이지 기준과 원본 시간 단위도 미확정이다. 초 단위 및 절대압 해석을 조건부로 명시했다. 흡수 평형 엔탈피 추정이 허용 상한80kJ/mol에 도달해 계수 식별성이 제한된다. 이 값을 독립적으로 측정한 열역학 물성으로 취급하지 않는다. 수소화물 평형식이나 유한 저장조의 열·질량 전체를 검증한 것은 아니다.

## 3. PEM분극 손실식

출처는 [Brundiers 등의 PEM데이터 v1](https://doi.org/10.5281/zenodo.19361280), CC BY4.0이다. 실험 면적4cm²와 운전 조건을 원본 설명 자료에서 확인했다. 네 셀의 첫 POL_GEIS곡선을 계수 추정에, 두 번째 곡선을 평가에 사용했다. 기존 SymmetricButlerVolmerLoss·OhmicLoss와 보정용 전압 오프셋을 사용했다. 반응 엔탈피나 Gibbs에너지를 임의로 만들어 전체 스택의 정확도를 주장하지 않았다.

낮은 전류에서의 crossover영향에 관한 원자료 설명에 따라 계수 추정은0.05A/cm²이상으로 사전 제한했다. 평가 자료는 낮은 전류까지 모두 포함했고, 실제 추정 전류 범위 밖의 점도 남겨 표시했다. 동일 셀·동일 장치의 반복 곡선이므로 독립 셀/실험실 재현은 아니다.

| 셀 | 추정점 | 평가점 | 평가 RMSE(mV) |
| --- | ---: | ---: | ---: |
| Reference |11|12|10.606|
| PtNano |14|18|32.554|
| PtBlack |13|18|21.038|
| PtC |8|8|13.672|

실제 반응 온도 대신 셀 블록 온도를 대용으로 사용했다. 세 셀의 교환전류 추정은 상한100000A/m²에 걸렸고 Jacobian조건수도 약9×10⁴–1.36×10⁵로 크다. 따라서 활성화 계수를 실제 재료 상수로 보고하지 않는다. 전압 오프셋은 알 수 없는 가역전압·기준·압력 영향을 포함하며, 수소량·열역학·효율은 이번 검증 대상이 아니다.

## 4. 고정 방출계수의 노즐 조건간 비교

출처는 [Grune·Sempert의 HyTunnel실험](https://zenodo.org/records/4668554), CC BY4.0이다. 이 자료는 공간 제트 측정이므로 잘 혼합된 구획의 시간 이력 검증에 전용하지 않았다. 여기서는 일관된4mm노즐의 차분한 기류 조건에서 기록된 유량·주변 조건만 사용했다.

약1g/s조건13개 스캔행으로 방출계수0.342315를 추정하고, 계수를 고정한 채 약5g/s조건22개 스캔행을 예측했다. 같은 자료를 계수 추정과 평가 양쪽에 넣지 않았다. 기존 HomogeneousIsentropicNozzle와 CoolProp만 사용했으며 새 유동식은 만들지 않았다. 원자료의 방출 과압에 주변 압력을 더해 절대압으로 변환했다.

약1g/s계수 추정 자료의 평균 절대 상대오차는0.867%지만, 약5g/s평가에서는29.83%이고 전부 낮게 예측했다. 작은 보정 오차를 다른 운전 조건의 정확도로 일반화하면 안 된다는 결과다. 실제 노즐 기체 온도가 없어 주변 온도를 사용했으며 압력 측정점에서 노즐까지의 손실과 센서 불확실성도 미확정이다. 따라서 원인이 노즐식 자체라고 단정하지 않고, 현재 고정 계수·경계조건 가정의 전이 성능이 부족하다고 기록한다. 스캔행들은 같은 운전 조건을 공유하므로 독립 실험22회로 세지 않는다.

## 재현과 파일

프로젝트 루트의 기존 h2physics-py312환경에서 실행한다. 새 자료의 메타데이터·해시는 research/data/hydride-kinetics-measured-holdout.toml과 pd-permeance-measured-holdout.toml에 기록했다. 두 새 메타데이터 레코드는 기존 스키마 검사에서 필수 누락이 없으며, 제3자 구성요소 권한 검토 미완료는 그대로 명시했다. 원자료와 원본 설명 그림은 배포에 포함하지 않는다.

```powershell
python scripts/validate_material_experiments.py --acquire
python scripts/validate_storage_experiments.py --archive data/raw/hydride-kinetics-measured-holdout/v1.0/hydride-kinetics-v1.zip
python scripts/validate_electrochemical_experiments.py
python scripts/validate_nozzle_experiments.py
```

수소화물 ZIP과 기존 PEM/HyTunnel자료는 각 출처 기록의 URL·해시로 별도 확보해야 한다. 자동 계수 추정 결과는 생산 기본값에 반영하지 않는다. 각 스크립트의 결과 파일은 무시된 artifacts/physical-validation-20261102에 저장된다. 원자료·개별 평가 행·비교 그림은 로컬 연구 산출물이며, 공개 보고서에는 원본 작성 집계·방법·출처만 담았다.

최종 집계 summary.json과 각 결과의 파일/스크립트 해시를 대조했다. 제품 소스365개는 이전 기본 시험 체크포인트와 동일하다. 분석 스크립트4개는 Ruff검사를 통과했다. 저장·재료·전기화학을 병렬 처리하면서 출처 조건 확인과 노즐 비교를 병행했다. 기존 엔진 자체의 물리 검증이나 새 모델 구현으로 작업을 확장하지 않았다.

## 현재 판단과 남은 근거

현재는 네 대상에 대해 **계수 추정 자료와 분리된 실측 예측 오차를 얻은 단계**다. 투과식은 명시한 범위에서 정량 근거를 확보했고, 분극·반응분율은 계수 식별성과 입력 정의의 제한이 있다. 노즐 조건간 오차는 크다. 다음에 자격 검증을 진행하려면 실제 반응/기체 온도, 압력·시간 기준, 물성·용량의 독립 측정값, 불확실성 또는 목적별 허용오차가 필요하다. 이 누락을 가정으로 감춰 전체 모델 검증 완료로 표시하지 않는다.
