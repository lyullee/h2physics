# h2physics — 수소 설비·저장·안전 물리 모델

수소 생산, 저장, 이송, 재료 거동과 사고 결과를 Python 객체로 계산하고 연결하는 연구용 라이브러리입니다. 파라미터 객체·함수·NumPy 배열·시간 이력을 직접 전달하므로 별도 서버나 직렬화 형식이 필요하지 않습니다.

첫 공개 배포를 준비하고 있습니다. 패키지·import 이름은 현재 `h2physics`이며, 공개 레지스트리의 실제 버전과 배포 여부는 릴리스 기록에서 확인해야 합니다. [영문 README](README.md), [빠른 시작](docs/QUICKSTART.md), [상세 사용자·연구자 안내](docs/USER_GUIDE_KO.md)를 함께 사용하세요.

## 설치와 첫 실행

기록된 기준 환경은 Python 3.12입니다. 저장소를 내려받은 후 가상환경을 활성화하고 필요한 기능만 설치합니다.

```bash
python -m venv .venv
python -m pip install --upgrade pip
python -m pip install -e ".[thermo,hydraulics,test]"
```

PowerShell 활성화는 `.venv\Scripts\Activate.ps1`, POSIX 셸은 `source .venv/bin/activate`입니다. 공개 배포 후의 설치 명령은 `python -m pip install "h2physics[thermo,hydraulics]"`입니다. 배포 전에는 소스 설치를 사용하세요.

```python
from h2physics.thermo import CoolPropProperties

state = CoolPropProperties("Hydrogen").state_pt(200_000.0, 300.0)
print(state.density_kg_m3)
print(state.enthalpy_j_kg)
print(state.basis)
```

압력은 절대압 Pa, 온도는 K입니다. 물성·수력학·전기화학의 실제 호출 예제와 오류 처리는 [빠른 시작](docs/QUICKSTART.md)에 있습니다.

## 제공 분야와 선택 수준

| 분야 | 주요 내용 |
| --- | --- |
| 열역학 | CoolProp 순수 유체·혼합물, 반응 엔탈피 기준, 검증된 테이블 인터페이스 |
| 설비·이송 | 탱크, 펌프, 밸브, 배관, 열교환기, 단열, 압축, 릴리프, 회수, 유한 이송 |
| 저장 | 수소화물, 흡착, 액상 운반체·암모니아, 미소구, 다공성·지하 저장 인터페이스 |
| 생산·분리 | 전해조·연료전지, PV 결합, 광화학·유한 반응, 막·PSA 등 선택 모듈 |
| 재료 | 용해·투과·확산·트랩, 열·응력, 건전성 인터페이스 |
| 안전 | 기체·액체·이상 노즐, 유한 방출원, 액적·충돌·풀, 확산·화재·노출 인터페이스 |
| 시설·연구 | 네트워크, 센서·경보·차단, 검출기 투표, 조건부 위험도, 불확실성·경제성 |

전체 카탈로그는 82개 항목이며 최근 시험 범위는 78개 주제 분야입니다. 독립 물리식 개수나 전체 검증 완료 수치가 아닙니다. 같은 분야에도 해상도·경계조건·외부 엔진이 다른 선택 수준이 있습니다. [모델 선택](docs/MODEL_SELECTION.md), [카탈로그](docs/MODEL_CATALOG.md), [Python 심볼 색인](docs/PUBLIC_API_INDEX.md)에서 실제 함수를 확인하세요.

유체 열물성은 CoolProp 또는 해당 공급자와 비교하여 자격을 확인한 테이블을 사용합니다. 오류가 나면 다른 EOS로 조용히 대체하지 않습니다. 고압 기체 수소 확산의 우선 공급자는 HyRAM+, 액화수소 유래 확산은 SLABx-LH2입니다. LH2DT, Cantera, PSA-Dyna, HELPR 등은 별도 설치·버전·라이선스 조건을 갖습니다. `pip install h2physics`만으로 모든 외부 엔진과 실험자료가 설치되지는 않습니다.

## 단위와 연결 규칙

- 기본 단위는 Pa 절대압, K, kg, m, s입니다. 게이지압·섭씨·정상체적 유량은 명시적으로 변환합니다.
- H와 H₂의 운반체 기준, 상, 스핀 조성, 엔탈피 기준을 유지합니다.
- 시간축 이름만 같다고 실제 시각·지지 구간이 일치하는 것은 아닙니다.
- 유량 하나를 완전한 사고 방출원으로 취급하지 않습니다. 개구·위치·재고·상·종료 조건이 필요합니다.
- 결과 소유자와 기준을 요구하는 수신 API에는 원본 결과를 전달합니다. 결과를 복사하거나 이름만 바꿔 자격을 만들어서는 안 됩니다.

## 실제 확인된 범위

| 단계 | 기록된 결과 |
| --- | --- |
| 입력 검사 | 78/78개 분야, 162개 시험 통과 |
| 계산식 확인 | 66개 분야, 67개 시험 통과; 핵심식·보조 계산·항등식 구분 |
| 극단값·경계 | 66개 분야, 108개 시험 통과; 수치 계산과 영역 경계 검사 구분 |
| 모듈 연결 | 정상 연결 72개, 거부 경계 2개, 외부 차단 2개, 별도 수신 대상 없는 결과 2개 |
| 기존 기능·대표 실행 | 선택한 기존 시험 50개, 대표 입력→출력 6개 통과 |
| 실측 비교 | 네 종류의 조건부 분리 평가 수행; 전체 물리 자격 검증 완료로 표시하지 않음 |

실측 비교는 유효 수소 투과식, 정규화 수소화물 반응분율, PEM 분극 손실식, 고정 방출계수의 노즐 유량식을 대상으로 했습니다. 자료 보정과 평가를 분리했지만 측정 불확실성·경계조건·계수 식별성의 한계가 남습니다. 특히 노즐은 다른 유량 조건에서 평균 상대오차 약 29.8%를 보였습니다. 각 오차는 물리량과 정의가 다르므로 하나의 정확도 점수로 합치지 않습니다.

[입력](docs/INPUT_CONTRACT_CAMPAIGN.md) · [계산식](docs/FORMULA_CONTRACT_CAMPAIGN.md) · [극단값](docs/EXTREME_CONTRACT_CAMPAIGN.md) · [연결](docs/CONNECTION_CONTRACT_CAMPAIGN.md) · [회귀·대표 실행](docs/REGRESSION_REPRESENTATIVE_CAMPAIGN.md) · [실측 비교](docs/PHYSICAL_VALIDATION_CAMPAIGN.md)

실행 성공, 수식 구현 확인, 실험 예측 정확도, 실제 시설 적용 자격은 서로 다른 상태입니다. 외부 엔진 내부 물리와 전체 연결 시설의 독립 물리 검증은 이번 범위에서 제외했습니다.

## 연구를 이어가는 순서

1. [연구 재개 안내](docs/RESEARCH_CONTINUATION.md)와 [개발 이력](docs/DEVELOPMENT_HISTORY.md)에서 마지막 상태·변경 이유를 확인합니다.
2. [API](docs/API.md)·[모델 선택](docs/MODEL_SELECTION.md)에서 사용할 함수와 수준을 정합니다.
3. 공급자·자료의 버전, 입력 단위·시간축·물질·에너지 기준을 고정합니다.
4. 관련 보고서의 명령으로 기존 결과를 재현하고 원래 실패·누락 조건을 보존합니다.
5. 새 자료는 계수 추정용과 평가용으로 구분하고, 결과·오차·적용 범위를 함께 기록합니다.

외부 엔진을 확장해야 할 때는 같은 수준의 중복 솔버를 새로 만들기보다 [수신 엔진 요청서](requests/README.md)를 작성합니다. 현재 알려진 차단·거부·종단 결과는 연결 보고서에 개별 사유가 있습니다.
